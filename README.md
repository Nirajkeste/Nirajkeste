## 🔌 Embedded and Hardware Projects

| Project | What it does | Tools |
|---|---|---|
| **Ultrasonic-Based Servo Control System (Bare-Metal AVR)** | Bare-metal firmware for the ATmega328P, written in pure C without any Arduino libraries. Timer1 Fast PWM provides precise servo control, and echo-pulse polling measures distance with an HC-SR04 ultrasonic sensor. A custom UART driver logs the distance live, and the servo moves automatically when the distance crosses a set threshold. | C, ATmega328P (AVR) |
| **LoRa Weather Monitoring System** | A battery-powered LoRa (868 MHz) system for environmental monitoring. An ESP32 transmitter collects data from five sensors (DHT11, BH1750, BMP280, MQ135 and UV) and sends it over long range, independent of WiFi. The receiver shows the data on an OLED display and syncs it to Blynk IoT for remote monitoring. | ESP32, LoRa, Blynk IoT |
| **ESP32 PCB Design** | A complete two-layer PCB for an ESP32-based system, covering the full workflow from schematic capture to final layout. I selected components by analyzing datasheets and created custom footprints for parts missing from the standard libraries. Component placement and routing were planned to reduce noise and maintain signal integrity. | KiCad |
| **ESP32-CAM Face-Detection Robot** (Coding and Circuit Labs, May to June 2026) | Designed a two-layer PCB and 3D CAD models for a face-detection robot built on the ESP32-CAM. I handled the hardware end to end, from schematic design to enclosure design, and wrote documentation on ESP32 setup and sensor integration. | KiCad, ESP32-CAM |
| **Real-Time Temperature Monitoring System** (Freelance) | A real-time temperature and humidity monitoring solution for an external client, built on an ESP32 with a DHT22 sensor. Readings are monitored remotely through the Blynk IoT platform. I managed the project independently from start to finish, from understanding the requirements to hardware setup, firmware development and testing. | ESP32, DHT22, Blynk IoT |
| **Robocon 2025** (DD Robocon, IIT Delhi) | Designed the custom PCB for the competition robot, ensuring proper sensor integration and reliable power distribution to all components. I worked closely with the mechanical and firmware teams to match the hardware to the robot's requirements, and gained hands-on exposure to STM32 microcontrollers and communication protocols. | KiCad, STM32 |
